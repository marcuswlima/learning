# Extrato

## Fatura Fechada

### Geara aquivo `saida.txt`
1. www.santander.com.br - Baixar a fatura fechada
1. Criar o arquivo `yyyy-mm.txt` (UTF-8)
1. Colar os lancamento da fatura no aquivo `yyyy-mm.txt`
1. Alterar `fatura-fechada.py` para referenciar o Mês a ser processado
1. Executar `fatura-fechada.py` para gerar arquivo `saida.txt`

### Geara aquivo
1. Abrir `saida.txt` com Editor de Planilha Eletrônica (EPL)
1. Organizar os dados por valor
1. www.organize.com.br - fazer o dowload do mes
1. `VALORNUMERICO(D1;".";",")=VALORNUMERICO(I1;".";",")`
